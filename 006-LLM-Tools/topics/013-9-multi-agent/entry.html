Messages are unit of context for models in langchain

MESSAGE

│

├── Role

│ ├── System

│ ├── Human/User

│ ├── AI/Assistant

│ └── Tool

│

├── Content

│ └── Actual message/data

│

└── Metadata

└── Additional information

messages = [

SystemMessage(content="You are a helpful assistant."),

HumanMessage(content="What is LangChain?"),

AIMessage(content="LangChain is a framework for building LLM applications.")

]

HumanMessage is LangChain's class for a user message, rather than UserMessage.

Model gives o/p is AI messages

Human gives i/p is Human message

model.invoke("Why do parrots talk?") ##Human Messages

O/p will be AI Message

text prompts:

A text prompt is the simplest way to give instructions/input to an LLM as plain text.

Text prompt vs Message

TEXT PROMPT

───────────

"Explain LangChain"

↓

Simple text input

MESSAGE

───────

Role → user

Content → "Explain LangChain"

Metadata → additional information

Detailed Message

system_msg = SystemMessage("""

You are a senior Python developer with expertise in web frameworks.

Always provide code examples and explain your reasoning.

Be concise but thorough in your explanations.

""")
