Pydantic

Pydantic models provide the richest feature set with field validation, descriptions, and nested structures.

because of field validation , value of string should string only else encounter with error.

One common LangChain approach is a Pydantic schema:

from pydantic import BaseModel, Field

class Person(BaseModel):

name: str = Field(description="Person's name")

age: int = Field(description="Person's age")

profession: str = Field(description="Person's profession")

Then provide this schema to the model:

structured_model = model.with_structured_output(Person)

result = structured_model.invoke(

"Tarun is 43 years old and works as a Python developer."

)

print(result)

===========================================================================

TypedDict is a Python typing feature that lets you define the expected structure of dictionary data.

In LangChain, it can be used as a schema for structured output when you want to describe the expected fields but don't need runtime validation like Pydantic provides.

--------No runtime validation of fields/data types.

Remember: TypedDict describes the shape of the data, while Pydantic can additionally validate the data at runtime.

===========================================================================

A dataclass is a Python feature used to define a structured data object using a class

Structured Output

│

├── TypedDict

│ → Simple dictionary structure

│ → No runtime validation

│

├── Dataclass

│ → Structured Python object

│ → Can contain methods/defaults

│

└── Pydantic
