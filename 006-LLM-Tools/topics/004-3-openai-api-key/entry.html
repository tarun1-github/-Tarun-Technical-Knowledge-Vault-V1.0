Tools in LangChain

Tools are pairing of schema, argument, function.

from langchain.tools import tool

@tool

def add_numbers(a: int, b: int) -> int:

"""Add two numbers together."""

return a + b

@tool

↓

LangChain converts Python function

↓

Tool schema

↓

LLM can understand:

Tool name → add_numbers

Description → Add two numbers together

Inputs → a, b

The docstring is important because it helps the model understand when and how to use the tool.

You can directly bind tools to a model:

model_with_tools = model.bind_tools([add_numbers])

The model may return a tool call rather than directly calculating the answer.

response = model_with_tools.invoke(

"What is 25 + 35?"

)

Multiple tools

from langchain.agents import create_agent

from langchain.tools import tool

@tool

def add(a: int, b: int) -> int:

"""Add two numbers."""

return a + b

@tool

def multiply(a: int, b: int) -> int:

"""Multiply two numbers."""

return a * b

@tool

def divide(a: int, b: int) -> float:

"""Divide a by b."""

return a / b

agent = create_agent(

model="openai:gpt-5.4",

tools=[add, multiply, divide]

)
