1. Prompt chaining in langgraph

Prompt chaining means breaking one complex task into multiple smaller LLM prompts, where the output of one step becomes the input to the next step.

Prompt Chaining = sequentially connect multiple LLM prompts.

2.) Parallaization in Lanngraph :

Parallelization means running multiple independent tasks at the same time instead of waiting for one task to finish before starting the next.

If Task A, B, and C don't depend on each other:

┌──→ Task A ──┐

│ │

START ───────────┼──→ Task B ──┼──→ Aggregator → END

│ │

└──→ Task C ──┘

Independent Nodes

↓

Parallel Execution

↓

Aggregator

↓

Combined Result

Chaining = "Do this, then this."

Parallelization = "Do these together."
