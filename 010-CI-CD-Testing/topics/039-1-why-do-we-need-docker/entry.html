1. Why do we need Docker?

"It works on my machine, but it doesn't work on another machine."

Suppose Developer A builds an application:

Developer A. The application works perfectly.

│

├── Windows

├── Python 3.12

├── LangChain 1.x

├── LangGraph

├── FastAPI

├── Other libraries

└── Configuration

----------------------------------------------------------

Now we move it to Developer B / QA / Production:

Developer B / Server . The application may fail.

│

├── Linux

├── Python 3.11

├── Different library versions

├── Different OS libraries

└── Different configuration

----------------------------------------------------------

Docker solution : Docker packages the application together with its required environment.
