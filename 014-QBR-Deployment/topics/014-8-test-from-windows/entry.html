Phase 3 — Remove passwords from environment variables

For production, we'll change the application to support:./secrets/db_password

Docker Compose secrets are specifically designed for passwords, certificates and API keys that shouldn't be stored in Dockerfiles or source code. They are mounted into the container under /run/secrets/<secret_name>

Phase 6 — How I recommend transferring the application

Model A — Git-based deployment

Model B — Image-based deployment — my preference

docker save qbr-dashboard:1.0.0 -o qbr-dashboard-1.0.0.tar

Transfer the image through the client's approved software-transfer mechanism.

docker load -i qbr-dashboard-1.0.0.tar
