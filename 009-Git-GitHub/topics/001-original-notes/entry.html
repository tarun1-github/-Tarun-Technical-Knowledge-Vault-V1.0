Git — Restore, Reset, Diff, Branch & Log
git restore vs git reset

Primarily used to restore files / undo changes in the working tree or staging area.

Unstage a file

git restore --staged README.md

Discard changes in working directory

git restore README.md
git reset is more powerful and can move the HEAD/branch pointer and/or change the staging area.
git reset --soft HEAD~1  ##Undo the last commit but keep changes staged.

Commit
