Q1. Why does a Docker container exit?

A container remains running as long as its main/foreground process is running. When that process exits, the container stops.

Q2. What is CMD?

CMD defines the default command or arguments executed when a container starts.

Q3. What is ENTRYPOINT?

ENTRYPOINT defines the main executable that the container is designed to run.

Q4. What is ARG?

ARG is primarily a build-time variable used during Docker image construction.

Q5. Why use ENV?

Environment variables allow application configuration to be changed without modifying or rebuilding the application code/image.

Q6. What does docker inspect do?

It displays detailed low-level configuration and runtime information about Docker objects such as containers and images.

docker run -d --name=redis redis
