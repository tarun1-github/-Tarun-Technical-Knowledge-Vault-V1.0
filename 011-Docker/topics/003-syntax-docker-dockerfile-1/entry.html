Problem 3 — Architecture lock-in

Traditional builds can result in an image built for a specific CPU architecture.

Developer machine

↓

x86/amd64

↓

Docker image

↓

Works on amd64

Then someone tries to run it on:ARM64 and you can encounter: exec format error

This becomes particularly important with:

Intel/AMD servers → amd64

Apple Silicon → arm64

AWS Graviton → arm64

Modern solution — Multi-platform builds

BuildKit/buildx can build for multiple architectures.

docker buildx build --platform linux/amd64,linux/arm64 -t myapp:latest .

You can use the same image name/tag: myapp:latest. This is called a multi-platform image.
