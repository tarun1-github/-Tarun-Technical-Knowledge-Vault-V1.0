Problem 2 — Secrets can leak

Suppose you need an API key during the build.

A bad approach is: The problem is that secrets can become part of the image's build history or metadata.

dockerfile

ARG API_KEY=[REDACTED]

RUN some-command --api-key=[REDACTED]

You can inspect image history with: 🚨 Never put production secrets directly into a Dockerfile.

docker history --no-trunc myapp
